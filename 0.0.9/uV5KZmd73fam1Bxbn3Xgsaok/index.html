Definition

Initial, successor, and index are a conceptual device of INFINITY: the initial is a first; the successor is a next; the index is a position, the count of nexts from the first. From these three comes counting, and with counting the potential infinite: there is always a next.

Example

Zero; the next; the next after that; and so on.

History Note

  • Aristotle: number is potentially infinite, since one can always add another (Physics III.6, 206b).
  • Richard Dedekind (Was sind und was sollen die Zahlen?, 1888) and Giuseppe Peano (Arithmetices principia, 1889) build the natural numbers from a first and a successor. Wikipedia: Peano axioms
  • Wittgenstein's pupil who, told to add two, continues 1000, 1004, 1008 (Philosophical Investigations §185, 1953).

Scope Note

The initial is where counting starts, not what started the world: to read a first cause into it is to misapply INFINITY. The antinomy nearby is Absolute Beginning.
