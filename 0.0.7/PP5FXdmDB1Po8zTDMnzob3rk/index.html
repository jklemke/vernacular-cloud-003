Definition

Mathematics, or logico-mathematics, is the jurisdiction that discovers, invents, and maintains abstract deductive grammars: arithmetic marks time, geometry marks space, and set theory marks isolates, aggregates, and voids.

Its tribunal is proof, and the community of mathematicians that checks it. Logic and mathematics are syntactic engineering: the building of a monotonic, axiomatic, extensional, deductive language.

History Note

  • Euclid's Elements: geometry built from definitions, postulates, and common notions (c. 300 BCE).
  • Kant: geometry rests on the pure intuition of space, arithmetic on that of time (Prolegomena §10, 1783).
  • Zermelo's axioms for set theory (1908); Whitehead and Russell's Principia Mathematica (1910–13). SEP: Set Theory
  • Gödel: no consistent formal system rich enough for arithmetic proves all arithmetic truths (1931).

Scope Note

Mathematics is not one of the Physical Realms, and not a description of the world: it marks the Unsayables (time, space, isolate, aggregate, void) and keeps the grammars that do so in order. The antinomy nearest it is Absolute Grammar.
