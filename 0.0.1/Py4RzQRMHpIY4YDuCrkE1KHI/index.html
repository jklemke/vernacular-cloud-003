concept: aggregate

concept-key: https://vernacular.cloud/0.0.1/Py4RzQRMHpIY4YDuCrkE1KHI/

Definition

group, collection, set, plurality, a motley plethora. The mereological powerset of all combinations of particles. There are more sets of sets than there are sets.

A fusion is an aggregate formed by listing the roster of elements. (extensional, by list)

A class is an aggregate formed by specification of a property rule. (intensional, by rule)

A set is an aggregate formed by membership in other sets (by list or by rule are equivalent)

A domain is an aggregate formed by metalanguage.

Fundamental theorem of a set can be defined by either rule, or list.
