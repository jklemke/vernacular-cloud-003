Definition

Logos, language, broadly conceived. Grammar, syntax, and semantic operations that enable sapient practice.

Cite Robert Brandom's notion of an autonomous discursive practice. A vocabulary that can be deployed though it contains no other vocabulary. But the key distinction is whether a language contains its metavocabulary. A natural language is one that contains its own metavocabulary. This is what distinguishes a completely grammatical language from a synthetic language. Or an informational code like DNA. This is the grammatical strange loop, comparable to Hofstadter's strange loop of consciousness.

Syntax are the rules of information format. Grammar are the rules by which language maps to the sentient, social, ostensive world.

Language can be:

  • talking about things (ostensive)
  • talking about talking (metalinguistic)
  • talking about talkers (heterosubjectivel)

If in an investigation explicit reference is made to the speaker, or, to put it in more general terms, to the user of a language, the we assign it to the field of pragmatics. And if, finally, we oubliate the designata also and analyze only the relations between the expressions, we are in (logical) syntax. The linguistic turn

The linguistic turn pretends to have replaced the unacceptably metaphysical thing-in-itself with a suitably 'real' proposition as an abstract sentence. This is a behaviourist, expressivist approach to meaning. Meaning as anthropology. The anthropologist oubliates his own self, by studying what is meant by language.
