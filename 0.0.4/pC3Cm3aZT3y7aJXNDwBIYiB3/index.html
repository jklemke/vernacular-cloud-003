Definition

The recept-aspect-object interpretive template is applied to three very different realms. Think of a bear, a toothache, and a memory as paradigmatic. You can run from a bear, but you can't run from a toothache or a memory. A toothache has a physical locus in my body. A memory is located in the same central realm in which the subject, conjecture, thoughts and emotions come and go.

The cogito demands external, internal and central. I think, therefore external, internal, central,aspect, object, subject. But IPSEITY is last on the list and subjectivity is a precondition of cogito and does not "exist".
