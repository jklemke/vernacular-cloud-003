Definition

See Russell "On Denoting". Compare Quine on refer versus denote.

The subject of a sentence. Indicative mood. The grammatical operation of referring to an object, an event, a situation, an isolate, an aggregate, a parameter, a conjecture.

Note the grammatical notions definite indication (the dog) and indefinite description (a dog).

Compare Sellars on picturing. Compare parameterized indication, ostensive indication, descriptive indication.

Compare de re and de dicto. The table is brown. The brown table is wooden. That is a brown table. That brown object is a table.

Table is predicative or indicative.
