Definition

A perspective is always local. There is no global perspective, but there is an abstract, generalized perspective. See the big bang, and puzzles over eternity from Aristotle, Avicenna, Ghazali. Kant has "solved" this is in the sense that he has indicated it as an antinomy.

This puzzle illustrates the antinomy: If a tree falls in a forest and there is no one around, does it make a sound? The recommendation is to label it as an antinomy rather than to argue about the details.
